# برنامج الاختبارات

برنامج اختبارات تفاعلي عربي لويندوز، يعمل دون إنترنت. فيه منصة للمدرب ومنصة للمتدرب، ويدعم اختبارات الدورات والترفيع والاختبارات السريعة والمفاجئة.

- المتطلبات الكاملة: [`docs/design.md`](docs/design.md)
- خطة التنفيذ ومراحله: [`docs/build-prompt.md`](docs/build-prompt.md)

## حالة التنفيذ

| المرحلة | الحالة |
|---|---|
| 0. تجربة الماوسين (متدربان على كمبيوتر واحد) | ⏸️ مؤجلة بقرار المستخدم |
| 1. الأساس: الواجهة العربية، قاعدة البيانات، دخول المدرب | ✅ |
| 2. محرك حساب الدرجات وهندسة الصور وسحب الأسئلة | ✅ |
| 3. بنوك الأسئلة والمحرر والقوائم الجاهزة و«تجربة» | ✅ |
| 4. الصور ومحرر المناطق (دائرة ومربع) | ✅ |
| 5. الاختبارات الأربعة والسحب العشوائي والإعدادات والمعاينة | ✅ |
| 6. منصة المتدرب: التعريف، المحاولات، الوقت، النتيجة | ✅ |
| 7. النتائج والتفاصيل والتصدير إلى Excel والطباعة | ✅ |
| 8. الشبكة المحلية، والأجهزة المنعزلة (تصدير النتائج ودمجها) | ✅ |
| 9. نسخة الفلاش لويندوز، والنسخ الاحتياطي، ودليل المستخدم | ✅ |

دليل الاستخدام: [`docs/user-guide.md`](docs/user-guide.md). القرارات التقنية أثناء التنفيذ: [`docs/decisions-log.md`](docs/decisions-log.md).

## الاستخدام من الفلاش (دون تثبيت)

انسخ `ArabicExams-<version>-portable.exe` إلى الفلاش وشغّله. البيانات تُحفظ في مجلد `ExamsData` بجانبه، فتنتقل معه إلى أي كمبيوتر.

## تحميل نسخة ويندوز الجاهزة

كل رفع إلى GitHub يبني نسخة ويندوز تلقائيًا على جهاز ويندوز: من صفحة المستودع افتح **Actions**، ثم آخر تشغيل لـ «بناء نسخة ويندوز»، وحمّل `ArabicExams-windows-portable` من قسم **Artifacts** في أسفل الصفحة.

## بناء ملف ويندوز

```bash
npm install
npm run dist:win
```

الناتج في مجلد `release`: ملف محمول `ArabicExams-<version>-portable.exe`، وملف `ArabicExams-<version>-win.zip`.

## التشغيل على ويندوز

1. ثبّت [Node.js](https://nodejs.org) الإصدار 22 (LTS).
2. افتح موجّه الأوامر في مجلد المشروع، ثم:

```bash
npm install
npm run dev
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | بناء البرنامج وتشغيله |
| `npm test` | تشغيل الاختبارات |
| `npm run typecheck` | فحص الأنواع |
| `npm run lint` | فحص جودة الكود |
| `npm run dist:win` | بناء نسخة ويندوز المحمولة في مجلد `release` |

## أين تُحفظ البيانات

- **النسخة المحمولة** (الفلاش أو ملف zip): في مجلد `ExamsData` بجانب البرنامج.
- **أثناء التطوير** (`npm run dev`): في مجلد بيانات المستخدم `ExamsData`.

احتفظ بنسخة من مجلد `ExamsData` كنسخة احتياطية، أو استخدم «حفظ نسخة احتياطية» من شاشة «البيانات والشبكة».

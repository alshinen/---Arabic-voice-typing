# 🎤 Alshinen - برنامج الكتابة بالصوت

<div dir="rtl">

## 📖 نظرة عامة

**Alshinen** (الشينين) هو برنامج متقدم لتحويل الكلام إلى نص باللغة العربية (ولغات أخرى)، يعمل **بدون إنترنت** باستخدام نماذج Vosk أو Whisper المحلية. البرنامج يتميز بواجهة رسومية عصرية وسرعة عالية في التعرف على الصوت والكتابة التلقائية.

### ✨ المميزات الرئيسية

- 🌐 **يعمل بدون إنترنت** - باستخدام Vosk (محلي) أو Whisper
- 🇸🇦 **دعم كامل للعربية** - مع 14+ لغة أخرى
- 🌍 **ترجمة فورية** - ترجمة النص لـ 15 لغة عبر Google Translate
- ⚡ **سرعة فائقة** - كمون منخفض (0.8 ثانية فقط)
- 🎨 **واجهة عصرية** - CustomTkinter مع theme داكن
- 🔄 **تصفية ذكية** - يتجاهل الكلام المشوش والضوضاء
- ⌨️ **كتابة تلقائية** - يكتب في أي تطبيق نشط
- 🔧 **تحديث مباشر** - تغيير اللغة أثناء التشغيل
- 🚀 **بدء سريع** - فتح الواجهة في أقل من ثانية

## 🚀 البدء السريع

### 1️⃣ التثبيت

```bash
# إنشاء بيئة محلية للمشروع
python -m venv venv
```

على Windows افتح CMD داخل مجلد المشروع:

```bat
call venv\Scripts\activate.bat
rem تثبيت جميع المكتبات المطلوبة
python -m pip install -r requirements_advanced.txt
```

على Linux/macOS فعّل البيئة باستخدام `source venv/bin/activate`، ثم نفّذ أمر التثبيت نفسه. راجع [دليل البيئة الافتراضية](README_VENV.md) للتفاصيل.

ملفات `INSTALL_*.bat` الموجودة في المستودع مخصّصة لتثبيت مكونات معينة؛ ملف `requirements_advanced.txt` هو القائمة الكاملة.

### 2️⃣ تحميل النماذج

النماذج تُحمّل منفصلة عن ملفات المشروع. لتحميل نموذج Vosk العربي من البيئة التي ثبّت فيها المكتبات:

```bash
# تحميل نموذج Vosk العربي
python -c "from model_manager import ModelManager; ModelManager().download_model('ar')"
```

يمكنك أيضاً تحميل النماذج من داخل الواجهة الرسومية عبر زر **"تحميل النماذج"**. يحفظها مدير النماذج افتراضياً في `~/.voice_to_text/models/`، ويمكنه اكتشاف النماذج الموضوعة داخل `models/` في المشروع.

### 3️⃣ التشغيل

```bash
# طريقة 1: تشغيل البيئة الافتراضية على Windows
START_VENV.bat

# طريقة 2: تشغيل مباشر بعد تفعيل البيئة
python main_advanced.py
```

يمكن تشغيل `START.bat` بعد تفعيل البيئة؛ يستخدم أمر `python` المتاح ويشغّل `main_advanced.py` دون فرض تحميل Whisper.

إذا أردت استخدام Whisper، ثبّت `openai-whisper` في البيئة أولاً. يحتفظ المشروع بالملف الاختياري `download_and_run.py` لتحميل نموذج Whisper وتشغيل الواجهة.

## 📋 المتطلبات

- Python 3.8+
- PyAudio (للتسجيل الصوتي)

## 🎯 كيفية الاستخدام

### 🎤 الكتابة بالصوت

1. **افتح البرنامج** - شغّل `START_VENV.bat` أو فعّل البيئة ثم شغّل `python main_advanced.py`
2. **اختر اللغة** - من القائمة المنسدلة (العربية افتراضياً)
3. **ابدأ التسجيل** - اضغط زر "🎙️ ابدأ التسجيل"
4. **تكلم بوضوح** - سيظهر النص مباشرة
5. **الكتابة التلقائية** - النص يُكتب في التطبيق النشط تلقائياً
6. **إيقاف التسجيل** - اضغط "⏹️ أوقف التسجيل"

### 🌍 الترجمة الفورية

1. **سجّل أو اكتب النص** - اتبع الخطوات أعلاه للحصول على نص
2. **اختر لغة المصدر** - من القائمة "من:" (العربية مثلاً)
3. **اختر لغة الهدف** - من القائمة "إلى:" (الفلبينية مثلاً)
4. **اضغط "🔄 ترجم"** - ستظهر الترجمة فوراً
5. **اللغات المدعومة**: العربية، الإنجليزية، الفرنسية، الإسبانية، الألمانية، الإيطالية، البرتغالية، الصينية، اليابانية، الكورية، الروسية، التركية، الفارسية، الهندية، الفلبينية

**مثال**: تكلم بالعربية "مرحباً كيف حالك؟" ← اختر "عربي → فلبيني" ← احصل على "Kumusta ka?"

> **ملاحظة**: ميزة الترجمة تحتاج إنترنت (تستخدم Google Translate API)

### ⚙️ الإعدادات المتقدمة

- **وضع الإنترنت**: بدون إنترنت فقط / بدون إنترنت أولاً / إنترنت فقط
- **المحرك**: Vosk (سريع) / Whisper (دقيق) / Google (يحتاج إنترنت)
- **سرعة الكتابة**: قابلة للتعديل في `config.py`

## 🔧 الإصلاحات والتحسينات

### التحسينات الأخيرة

✅ **سرعة البدء** - من 10-30 ثانية إلى أقل من ثانية  
✅ **تصفية الضوضاء** - يتجاهل الكلام المشوش (اه، ام، ممم)  
✅ **إيقاف آمن** - لا تجميد عند إيقاف التسجيل  
✅ **تغيير اللغة السلس** - بدون تعليق البرنامج  
✅ **ظهور الواجهة** - توسيط تلقائي وظهور في المقدمة  
✅ **توقيت محسّن** - pause_threshold: 0.8s، phrase_limit: 8s

## 🐛 حل المشاكل الشائعة

### ❌ "فشل في تهيئة PyAudio"

```bash
# Windows - تثبيت PyAudio من wheel
pip install pipwin
pipwin install pyaudio

# Linux
sudo apt-get install python3-pyaudio portaudio19-dev

# macOS
brew install portaudio
pip install pyaudio
```

### ❌ "نموذج Vosk غير موجود"

```bash
# حمّل النموذج العربي
python -c "from model_manager import ModelManager; ModelManager().download_model('ar')"

# أو يدوياً من:
# https://alphacephei.com/vosk/models
```

### ❌ "keyboard library يحتاج صلاحيات مرتفعة"

- **Windows**: شغّل CMD/PowerShell كـ Administrator
- **Linux**: استخدم `sudo` أو استخدم `pyautogui` بدلاً منه (تلقائي)

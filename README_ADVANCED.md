# 🎤 برنامج الكتابة بالصوت - النسخة المتقدمة

برنامج متكامل لتحويل الكلام العربي إلى نص وكتابته تلقائياً في أي تطبيق.

للتثبيت من نسخة جديدة، اتبع [البدء السريع](README.md) و[إعداد البيئة الافتراضية](README_VENV.md). نقطة التشغيل المعتمدة هي `main_advanced.py`.

## ✨ المميزات

- ✅ **يعمل بدون إنترنت** - يستخدم Vosk أو Whisper محلياً
- ✅ **دقة عالية** - دعم ممتاز للغة العربية
- ✅ **يعمل مع أي تطبيق** - Word, PDF, Browser, Search, إلخ
- ✅ **واجهة عصرية** - باستخدام CustomTkinter
- ✅ **سريع وخفيف** - استجابة فورية
- ✅ **يدعم الأوامر الصوتية** - مثل "سطر جديد"، "نقطة"، إلخ

## 📋 المتطلبات

### متطلبات النظام:
- Python 3.8 أو أحدث
- Windows 10/11 (يمكن تعديله للعمل على Linux/Mac)
- ميكروفون متصل
- 2-4 GB مساحة إضافية للنماذج (اختياري)

### المكتبات المطلوبة:

#### المتطلبات الكاملة:
```bash
python -m pip install -r requirements_advanced.txt
```

#### محرك التعرف على الصوت (اختر واحد على الأقل):

**Whisper (موصى به للدقة):**
```bash
pip install openai-whisper
```

**Vosk (أخف وأسرع):**
```bash
pip install vosk
# ثم حمّل النموذج العربي من: https://alphacephei.com/vosk/models
```

تتضمن قائمة المتطلبات مكتبات الواجهة `customtkinter` و`Pillow`، ومكتبة `SpeechRecognition` التي يفحصها البرنامج عند بدء التشغيل.

## 🚀 التثبيت السريع

### الطريقة 1: تثبيت تلقائي (Windows)
```bash
# افتح الطرفية داخل مجلد المشروع وفعّل البيئة الافتراضية أولاً
# قم بتثبيت جميع المتطلبات
python -m pip install -r requirements_advanced.txt
```

### الطريقة 2: تثبيت يدوي

```bash
# 1. تثبيت المتطلبات في البيئة الافتراضية

# 2. تثبيت محرك التعرف (اختر واحد)
# Whisper (الأفضل للدقة):
pip install openai-whisper

pip install vosk

# 3. تحميل نموذج Vosk (إذا اخترت Vosk)
# اذهب إلى: https://alphacephei.com/vosk/models
# حمّل: vosk-model-ar-0.22
# ضعه في: models/vosk-model-ar-0.22/
```

## 📖 طريقة الاستخدام

### 1. تشغيل البرنامج:
```bash
python main_advanced.py
```

### 2. في الواجهة:
1. اضغط **"ابدأ التسجيل"**
2. تحدث في الميكروفون بوضوح
3. سيتم تحويل الكلام إلى نص تلقائياً
4. النص سيُكتب في التطبيق النشط (Word, Browser, إلخ)

### 3. الأوامر الصوتية المتاحة:
- "سطر جديد" → إدراج سطر جديد
- "نقطة" → .
- "فاصلة" → ،
- "علامة استفهام" → ؟
- "علامة تعجب" → !

## 🔧 الإعدادات

يمكن تعديل الإعدادات في ملف `config.py`:

```python
# اختيار محرك التعرف
RECOGNITION_ENGINE = "whisper"  # أو "vosk"

# حجم نموذج Whisper (كلما كبر كلما زادت الدقة والبطء)
WHISPER_MODEL_SIZE = "base"  # tiny, base, small, medium, large

# سرعة الكتابة
TYPING_DELAY = 0.01  # ثواني بين الأحرف
```

## 🐛 استكشاف الأخطاء

### مشكلة: "Whisper غير متاح"
**الحل:**
```bash
pip install openai-whisper
```

### مشكلة: "Vosk نموذج غير موجود"
**الحل:**
1. حمّل النموذج من: https://alphacephei.com/vosk/models
2. ضعه في مجلد `models/vosk-model-ar-0.22/`

### مشكلة: "keyboard غير متاح"
**الحل:**
```bash
pip install keyboard
# أو
pip install pyautogui
```

### مشكلة: "PyAudio خطأ"
**الحل (Windows):**
```bash
pip install pipwin
pipwin install pyaudio
```

### مشكلة: الدقة منخفضة
**الحل:**
- استخدم Whisper بدلاً من Vosk
- استخدم نموذج أكبر (medium أو large)
- تحدث بوضوح وبصوت مسموع
- قلل الضوضاء في الخلفية

## 💡 نصائح للاستخدام الأمثل

1. **استخدم ميكروفون جيد** - يحسن الدقة بشكل كبير
2. **تحدث بوضوح** - لكن بشكل طبيعي
3. **قلل الضوضاء** - في بيئة هادئة أفضل
4. **استخدم Whisper** - للدقة الأفضل (يحتاج مساحة أكبر)
5. **استخدم Vosk** - للسرعة والأداء (أخف)

## 1. الخلاصة

اكتمل البرنامج بكل ما اتُّفق عليه في `docs/design.md`، وهذه أهم خصائصه:

- **عربي بالكامل** ومن اليمين لليسار، ويعمل على ويندوز **دون إنترنت**.
- **يعمل من الفلاش:** البيانات تُحفظ بجانبه، فتنتقل معه إلى أي كمبيوتر.
- **منصتان منفصلتان:** منصة للمدرب ومنصة للمتدرب.
- **أربعة أنواع من الاختبارات:** دورة، وترفيع درجة، وسريع، ومفاجئ.
- **خمسة أنواع من الأسئلة:** صح أو خطأ، واختر الإجابة، واذكر، والمهارات، وسؤال الصورة.
- **وضع المقعدين:** متدربان في الوقت نفسه على كمبيوتر واحد بشاشتين، لكل منهما ماوس.

## 2. ما نُفّذ مقارنة بالمتطلبات

### 2.1 المنصتان
| المتطلب | التنفيذ |
|---|---|
| منصة للمدرب محمية | كلمة مرور مشفّرة (scrypt)، تُنشأ أول مرة، ويمكن تغييرها |
| منصة للمتدرب | صفحة الاختبارات المفتوحة فقط، مقسّمة حسب النوع، وتتحدث تلقائيًا كل 10 ثوانٍ |
| فصل الصلاحيات | الانتقال إلى منصة المتدرب يُخرج المدرب. أجهزة الشبكة ونافذة المقعدين لا تصل إلى أي دالة من دوال المدرب |

### 2.2 بنوك الأسئلة
| المتطلب | التنفيذ |
|---|---|
| بنك لكل مستوى ترفيع (4←3، 3←2، 2←1) | ✅ أسئلة كل بنك لا تظهر في غيره، ويُفرض ذلك في قاعدة البيانات |
| بنك عام للدورات (لا بنك لكل دورة) | ✅ |
| 50 أو 100 سؤال أو أكثر | ✅ لا حد للعدد |
| نسخ سؤال إلى بنك آخر | ✅ نسخة مستقلة |

### 2.3 الأسئلة
| النوع | التنفيذ |
|---|---|
| مشترك لكل الأنواع | درجة السؤال (¼، ½، 1، 2، أو أي رقم). عدد المحاولات (مبتدئ 3، متوسط 2، متقدم 1، أو أي عدد). طريقة احتساب المحاولة المتأخرة: خصم تدريجي، أو كاملة، أو من أول محاولة فقط |
| صح أو خطأ | الإجابة الصحيحة. وتنبيه إن وضع المدرب أكثر من محاولة، لأن المحاولة الثانية مضمونة الصواب |
| اختر الإجابة | بدائل قابلة للإضافة والترتيب، وخلط ترتيبها لكل متدرب |
| اذكر | عدد الإجابات، والترتيب مهم أو غير مهم، وقائمة مشتركة أو قائمة لكل موضع. **قائمة كبيرة مشوِّشة**: لصق الخيارات دفعة واحدة، وقوائم جاهزة، وتحذير إن قلّت عن 15 خيارًا. المكرر يُحسب مرة واحدة |
| المهارات | جدول بنود بلا حد، وقائمة خيارات مشتركة، ولصق بنود كثيرة، وثلاث طرق لتوزيع الدرجة: جزئي، أو كل شيء أو لا شيء، أو درجة لكل بند |
| سؤال الصورة | رفع الصورة، ورسم **دائرة أو مربع**، والتكبير والتصغير بالمقابض، والتحريك، وهامش تسامح. الإحداثيات نسب من الصورة الأصلية، فتبقى المنطقة مطابقة مع أي حجم شاشة |
| زر «تجربة» | السؤال يظهر بواجهة المتدرب نفسها، والمنطقة مخفية، والتصحيح فعلي. ثم «اعتماد» أو «رجوع للتعديل». السؤال الذي لم يُجرَّب عليه علامة «لم يُجرَّب» |

### 2.4 الاختبارات
| المتطلب | التنفيذ |
|---|---|
| اختبار دورة | رقم الدورة واسمها، والمدرب يختار الأسئلة من البنك العام بمربعات اختيار، مع درجة لكل نوع أو لكل سؤال |
| اختبار ترفيع | درجة الترفيع، و**سحب عشوائي مختلف لكل متدرب**: المدرب يحدد العدد والدرجة لكل نوع، ويرى المتوفر في البنك. الاختيار اليدوي متاح أيضًا |
| اختبار سريع | مرتبط بحصة، ولا وقت له، ويُظهر الإجابة الصحيحة افتراضيًا |
| اختبار مفاجئ | نوع مستقل، ومخفي حتى يضغط المدرب «ابدأ الاختبار المفاجئ الآن» |
| مجموع الدرجات | يُحسب تلقائيًا ويظهر في شريط ثابت |
| حد النجاح | نسبة (60٪ أو 70٪ أو 80٪ أو أي نسبة)، أو عدد درجات (مثل 3 من 5)، أو بلا حد |
| إعدادات أخرى | الوقت، وإظهار الإجابة الصحيحة بعد انتهاء المحاولات، وعدد مرات دخول المتدرب |
| المعاينة | تشغيل الاختبار كاملًا كما يراه المتدرب، ولا تُسجَّل |
| منع النشر الخاطئ | البرنامج لا ينشر اختبارًا بلا أسئلة، ولا اختبارًا لا يكفيه البنك، ولا اختبارًا حد نجاحه أكبر من مجموعه |

### 2.5 منصة المتدرب
| المتطلب | التنفيذ |
|---|---|
| التعريف | الاختيار من قائمة الأسماء (في الترفيع: أسماء الدرجة المناسبة فقط)، أو الرقم بلوحة أرقام على الشاشة («هل أنت: فلان؟»)، أو الرقم والاسم، أو الاسم |
| أسئلة مختلفة | الترفيع: أسئلة مختلفة لكل متدرب. كل الأنواع: ترتيب مختلف للأسئلة والبدائل |
| المحاولات | «حاول مرة أخرى (بقيت محاولة واحدة)». في «اذكر» لا يُخبَر المتدرب أي موضع أخطأ فيه، وتبقى إجاباته، وتُحتسب أفضل محاولة |
| سؤال الصورة | ضغطة على الصورة، ثم ✔ وانتقال تلقائي، أو ✘ ومحاولة أخرى |
| التنقل | للأمام فقط بعد التأكيد، مع «تأجيل» سؤال لم يُجب عنه بعد |
| الوقت | مؤقت مستقل لكل متدرب، وتسليم تلقائي عند انتهائه |
| الحماية من الانقطاع | كل إجابة تُحفظ فورًا، وإعادة الدخول تستأنف الاختبار نفسه |
| النتيجة | الدرجة من المجموع، والنسبة، وناجح أو راسب، ثم «إنهاء وتسليم الجهاز للمتدرب التالي» |

### 2.6 النتائج والبيانات
| المتطلب | التنفيذ |
|---|---|
| النتائج | قائمة مع تصفية حسب النوع والاختبار، وتفاصيل كل سؤال وكل محاولة، ومواضع الضغط على الصور |
| التصدير | Excel (CSV بالعربية)، والطباعة أو حفظ PDF |
| دخول إضافي | «السماح بدخول إضافي» لمتدرب معيّن |
| النسخ الاحتياطي | ملف واحد فيه كل البيانات والصور، ويمكن استعادته |
| الأجهزة المنعزلة | تصدير نتائج كل جهاز ثم دمجها في جهاز المدرب دون تكرار |
| الشبكة المحلية | يشغّل المدرب الخادم، فيفتح المتدرب العنوان في متصفح أي جهاز. لا تظهر له إلا منصة المتدرب |

### 2.7 وضع المقعدين
| المتطلب | التنفيذ |
|---|---|
| شاشتان، يمين ويسار، والمدرب في المنتصف | نافذة واحدة تغطي الشاشتين: **المقعد الأيمن** للمتدرب الأول، و**الأيسر** للثاني |
| في الوقت نفسه، وأسئلة مختلفة | كل مقعد منصة متدرب مستقلة بأسئلته ووقته ونتيجته |
| بالماوس | برنامج مساعد صغير (`rawmouse.exe`) يقرأ كل ماوس منفصلًا عبر Raw Input في ويندوز. لكل متدرب **سهم بلون مقعده**، محبوس في شاشته |
| عدم التداخل | سهم ويندوز المشترك ولوحة المفاتيح يُتجاهلان. القوائم والنوافذ المنبثقة محصورة في مقعد صاحبها |
| الربط | «حرّك ماوس الشاشة اليمنى» ثم «اليسرى»، ويُحفظ الربط. الخروج Ctrl+Shift+Q، وإعادة الربط Ctrl+Shift+R |
| شاشة واحدة | تُقسم نصفين |

## 3. كيف تحققت

### 3.1 الاختبارات الآلية (78 اختبارًا)
- **حساب الدرجات:** الحالات الـ18 المتفق عليها في `docs/build-prompt.md`، والخصم التدريجي، و«اذكر» بترتيب ودون ترتيب، والمهارات، وحد النجاح بالنسبة وبالدرجات، وأخطاء الكسور العشرية.
- **مناطق الصور:** الدائرة والمربع والمضلع، والضغط خارج الصورة، وثبات المنطقة مع اختلاف الأحجام، وهامش التسامح.
- **سحب الأسئلة:** الالتزام بالقالب، وعدم التكرار، واختلاف أسئلة المتدربين، وتجنب ما رآه المتدرب، ورفض البنك الذي لا يكفي.
- **الخدمات:**
  - البنوك ومنع خلطها، وحفظ الأسئلة والتحقق منها.
  - الاختبارات ونشرها، وسير الاختبار كاملًا.
  - الاستئناف بعد الانقطاع، وانتهاء الوقت، وإظهار الإجابة الصحيحة.
  - استيراد المتدربين من Excel، والنسخ الاحتياطي، ودمج نتائج جهاز منعزل.
  - التحقق من أن الإجابات الصحيحة لا تصل إلى المتدرب.
- **وضع المقعدين:** تخطيط الشاشتين، والشاشة الواحدة، والشاشة ذات الإحداثيات السالبة، وحبس السهم، وقراءة أسطر قارئ الفئران.

### 3.2 تجربة الواجهة الفعلية آليًا (Playwright على شاشة افتراضية)
| السيناريو | النتيجة |
|---|---|
| مدرب: صورة، وأسئلة بالأنواع الأربعة، وتجربة واعتماد، ورسم منطقة، واختبار مفاجئ ونشره وفتحه. ثم متدرب: يجيب ويسلّم | ✅ النتيجة 3.17 من 3.5 (90.48٪، ناجح)، وهي مطابقة للحساب اليدوي |
| ترفيع بسحب عشوائي، ومعاينة المدرب، وخادم الشبكة، ومتدربان من متصفح جهاز آخر | ✅ المتصفح لا يُظهر منصة المدرب. قائمة الأسماء لمتدربي الرابعة فقط. المتدربان أخذا أسئلة مختلفة (6 من 12) |
| وضع المقعدين بفأرين وهميين | ✅ الربط يعمل. الماوس الحقيقي يُتجاهل. المتدربان يعملان في الوقت نفسه بأسئلة مختلفة. إجابة الأول لا تؤثر في الثاني. نافذة التأكيد محصورة في مقعدها. دوال المدرب ممنوعة من النافذة |
| النسخة المغلّفة: تشغيلان متتاليان | ✅ مجلد `ExamsData` بجانب البرنامج، والتشغيل الثاني قرأ البيانات نفسها |

### 3.3 البناء على ويندوز
GitHub Actions يبني على `windows-latest` مع كل رفع، وفي كل بناء:
- فحص الأنواع وجودة الكود والاختبارات.
- بناء `rawmouse.exe` بمترجم Visual Studio.
- بناء الملف المحمول وملف zip.

## 4. التحميل والاستخدام

1. **التحميل:** من صفحة المستودع افتح **Actions**، ثم آخر تشغيل لـ «بناء نسخة ويندوز»، وحمّل **`ArabicExams-windows-portable`** من قسم Artifacts.
2. **الفلاش:** انسخ `ArabicExams-0.1.0-portable.exe` إلى مجلد على الفلاش، ثم شغّله.
3. **دليل الاستخدام خطوة بخطوة:** `docs/user-guide.md`.

## 5. ما يحتاج انتباهك

1. **أول تجربة على ويندوز:** شغّل البرنامج من الفلاش، وأنشئ سؤالًا واختبارًا، واختبر به. أخبرني بأي شيء لا يعمل.
2. **وضع المقعدين بفأرين حقيقيين:** هذا أهم شيء يحتاج تجربة. البرمجة مبنية على واجهة Raw Input في ويندوز، وهي معروفة وموثّقة. لكنها **لم تُجرَّب على جهازك**، وقد تختلف بعض الفئران أو لوحات اللمس في سلوكها. جرّب: الربط، ثم حركة السهمين معًا، ثم الضغط في المقعدين معًا.
3. **تحذير ويندوز (SmartScreen):** قد يظهر لأن البرنامج غير موقّع رقميًا. اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال». وقد يطلب جدار الحماية السماح عند تشغيل خادم الشبكة.
4. **الفلاش:** لا تفصله والبرنامج يعمل. أول تشغيل للملف المحمول يأخذ بضع ثوانٍ.
5. **قرارات اتخذتها نيابة عنك:** 18 قرارًا مسجلة في `docs/decisions-log.md`، منها حد النجاح الافتراضي 70٪، والمفاجئ 3 درجات. كلها قابلة للتغيير.

## 6. قيود معروفة وتحسينات ممكنة لاحقًا

| البند | الحالة |
|---|---|
| تعدد الإجابات المقبولة لموضع واحد في «اذكر» بترتيب | محرك التصحيح يدعمه، والواجهة لا تتيحه بعد |
| قائمة خيارات خاصة لبند معيّن في المهارات | غير متاح. القائمة مشتركة لكل البنود |
| البنود الحرجة، وتصنيف الصعوبة، وتعدد المدربين، وأقسام الاختبار | مؤجلة بالقرار 25 في `docs/design.md` |
| أيقونة خاصة للبرنامج وتوقيع رقمي | غير متوفرين. الأيقونة الحالية هي أيقونة Electron الافتراضية |
| كتابة الاسم في وضع المقعدين | غير متاحة لعدم وجود لوحة مفاتيح لكل متدرب. تُستخدم القائمة أو لوحة الأرقام |
